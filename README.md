# Interactive Robotics Learning Module

This is a simple web project made using HTML, CSS and JavaScript.  
The goal of this module is to help students understand basic robotics concepts like sensors, simulation and quiz-based learning.

The project has multiple pages:  
- Home  
- Learning Page  
- Simulation Page  
- Quiz Page  
- Result Page  
- Progress Page  
- About  

Everything is made without any frameworks.

---

# Project Overview

# Learning Page  
Basic explanation of commonly used robot sensors such as:
- Ultrasonic Sensor  
- Infrared Sensor  
- Touch Sensor  

# Simulation Page  
A small robot simulation created using JavaScript Canvas.  
The robot moves forward and stops when it detects an obstacle (simulated sensor logic).

# Quiz Page  
A short quiz with multiple-choice questions.  
The score is calculated instantly and stored in localStorage.

# Progress Tracking  
User’s last quiz score is stored locally so progress can be checked later.
